API REST desenvolvida em **Java** com **Spring Boot** para o cadastro, consulta, atualização e exclusão de animais disponíveis para adoção

## 🎯 1. Objetivo
O objetivo deste projeto é colocar em prática os conhecimentos de **Java**, **Spring Boot**, **Programação Orientada a Objetos (POO)** e **desenvolvimento de APIs REST**, criando um sistema funcional de gerenciamento de animais para adoção

## 🛠️ Tecnologias Utilizadas
O projeto foi construído utilizando as seguintes ferramentas e tecnologias:
* **Java** 
* **Spring Boot** 
* **IntelliJ IDEA** 
* **Postman** 

## 🔌Endpoints 

| Método | Endpoint | Descrição |
| :--- | :--- | :--- |
| **POST** | `/animais` | Cadastra um novo animal |
| **GET** | `/animais` | Lista todos os animais cadastrados |
| **GET** | `/animais/{id}` | Consulta um animal específico pelo ID |
| **PUT** | `/animais/{id}` | Altera os dados de um animal existente |
| **DELETE** | `/animais/{id}` | Exclui um animal do sistema |
